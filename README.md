# Автоматическое форматирование документов по ГОСТ 7.32-2017

Веб-приложение для автоматического форматирования документов Word (.docx) в соответствии с требованиями ГОСТ 7.32-2017 для выпускных квалификационных работ с использованием AI-анализа структуры документа.

## Возможности

- **AI-анализ структуры документа** с помощью Claude API
- **Автоматическое форматирование** согласно ГОСТ 7.32-2017:
  - Шрифт Times New Roman 14pt
  - Полуторный межстрочный интервал
  - Поля документа по стандарту (левое 3см, правое 1см, верхнее и нижнее 2см)
  - Выравнивание по ширине с отступом абзаца 1.25см
  - Форматирование заголовков прописными буквами по центру
  - Правильная нумерация разделов и подразделов
  - Оформление списка литературы по ГОСТ 7.0.5-2008

- **Drag-and-drop интерфейс** для удобной загрузки файлов
- **Асинхронная обработка** больших документов через Celery
- **История обработанных документов** с возможностью скачивания
- **Отслеживание статуса** обработки в реальном времени

## Технологический стек

### Backend
- **FastAPI** - современный веб-фреймворк для API
- **python-docx** - библиотека для работы с документами Word
- **Claude API** - искусственный интеллект для анализа структуры
- **PostgreSQL** - база данных для хранения истории
- **Celery + Redis** - асинхронная обработка задач

### Frontend
- **React** - современная библиотека для UI
- **react-dropzone** - drag-and-drop загрузка файлов
- **Axios** - HTTP-клиент для API запросов

### Инфраструктура
- **Docker & Docker Compose** - контейнеризация приложения
- **Nginx** - веб-сервер для frontend

## Быстрый старт

### Предварительные требования

- Docker и Docker Compose
- Claude API ключ (получить на https://console.anthropic.com)

### Установка и запуск

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd -docs-autoformat
```

2. **Создайте файл .env из примера:**
```bash
cp .env.example .env
```

3. **Добавьте ваш Claude API ключ в .env:**
```env
CLAUDE_API_KEY=your_actual_api_key_here
```

4. **Запустите приложение с помощью Docker Compose:**
```bash
docker-compose up --build
```

5. **Откройте приложение в браузере:**
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API документация (Swagger): http://localhost:8000/docs

## Использование

1. **Загрузите документ:**
   - Перетащите файл .docx в область загрузки или кликните для выбора файла
   - Максимальный размер файла: 10 МБ

2. **Дождитесь обработки:**
   - Система автоматически проанализирует структуру документа
   - Применит форматирование согласно ГОСТ
   - Статус обработки отображается в реальном времени

3. **Скачайте результат:**
   - После завершения обработки нажмите кнопку "Скачать"
   - Получите отформатированный документ

## API Endpoints

### Документы

- `POST /api/v1/documents/upload` - Загрузка документа
- `GET /api/v1/documents/documents/{document_id}` - Получение статуса документа
- `GET /api/v1/documents/documents/{document_id}/download` - Скачивание отформатированного документа
- `GET /api/v1/documents/documents` - Список всех документов

### Статусы документов

- `uploaded` - Документ загружен
- `processing` - Документ обрабатывается
- `completed` - Обработка завершена
- `failed` - Ошибка при обработке

## Разработка

### Локальная разработка backend

```bash
cd backend
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или venv\Scripts\activate  # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Локальная разработка frontend

```bash
cd frontend
npm install
npm start
```

### Запуск Celery worker локально

```bash
cd backend
celery -A app.tasks.celery_app worker --loglevel=info
```

## Модульность и расширяемость

Приложение спроектировано с учетом модульности:

- **Добавление новых шаблонов ГОСТ**: Создайте новый класс-наследник `GOSTFormatter`
- **Специфичные требования вузов**: Реализуйте дополнительные методы форматирования
- **Новые форматы документов**: Расширьте `DocxProcessor` для поддержки других форматов
- **Дополнительный AI-анализ**: Расширьте `ClaudeDocumentAnalyzer` новыми методами анализа

## Требования ГОСТ 7.32-2017

Приложение реализует следующие требования стандарта:

1. **Шрифт**: Times New Roman, 14 пунктов
2. **Междустрочный интервал**: 1.5
3. **Поля**:
   - Левое: 3 см
   - Правое: 1 см
   - Верхнее: 2 см
   - Нижнее: 2 см
4. **Абзацный отступ**: 1.25 см
5. **Выравнивание**: По ширине
6. **Заголовки**: Прописными буквами, по центру, без точки в конце
7. **Список литературы**: По ГОСТ 7.0.5-2008

## Troubleshooting

### Проблемы с подключением к базе данных

Убедитесь, что PostgreSQL контейнер запущен:
```bash
docker-compose ps
```

### Celery worker не обрабатывает задачи

Проверьте логи worker:
```bash
docker-compose logs celery_worker
```

### Frontend не может подключиться к backend

Проверьте переменную `REACT_APP_API_URL` и убедитесь, что backend запущен на правильном порту.
